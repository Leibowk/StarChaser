# **Welcome to StarChaser!!!**

Frontend:
React Native Expo

Backend:
Fast API

PreReques:
uvicorn

Start app: npx expo start --clear

Run Backend: uvicorn main:app --host 0.0.0.0 --port 3000 --reload

Can either run frontend on Expo Go from your phone or download an emulator like BlueStacks and use Expo Go there.
